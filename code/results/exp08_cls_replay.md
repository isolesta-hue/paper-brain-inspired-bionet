## 해석

**1. 기억이 가르치는 수면 재생(공고화)이 격자를 크게 끌어올린다 — 특히 tag12**
| tag12 | n=1000 | n=3000 | n=20000 |
|---|---|---|---|
| 격자만 (1회 통과) | 22.55 | 25.28 | 35.00 |
| + 실제 정답 재생 ×4 | 29.95 | 33.41 | 35.39 |
| **+ 기억의 답으로 재생 ×4** | **32.28** | **37.40** | **38.77** |
| (참고) 격자를 여러 에폭 반복 학습 | 32.39 | 35.90 | 38.97 |
- 데이터를 한 번씩만 본 격자가, 기억의 가르침을 받으면 **같은 데이터를 여러 번 반복 학습한 격자와 같거나 높다** (n=3000: 37.40 vs 35.90).
- 같은 재생 횟수라도 실제 정답보다 기억의 답이 낫다 (n=3000: 37.40 vs 33.41). 기억의 답은 비슷한 문맥들의 경험을 모아 만든 "부드러운 정답"이라
  잡음이 적은 것으로 해석된다 (일종의 지식 증류). content에서는 두 재생 방식이 비슷하다 (66.09 vs 65.49).

**2. 공고화 = 기억의 압축**
- 기억의 답으로 배운 격자 38.77% (파라미터 3,720개) ≈ 기억 자체 39.22% (저장 가중치 96,000개).
  큰 해마 기억의 지식이 약 26배 작은 피질 격자로 옮겨졌다. 사용자가 제기한 "기억 모델 크기" 문제의 생물학적 해법 후보:
  **기억은 임시 저장소로 쓰고, 수면 재생으로 격자에 옮긴 뒤 비운다** (CLS 이론의 예측과 같음).

**3. 이중 판정 (M-Path)**
- 검증으로 고른 비중 w가 대부분 0~0.25 → 최종 판단은 주로 기억이 한다. 이중 판정 ≈ 기억 단독 + 약간.
- 최고값: content dual+replay4 69.22 (n=20000), tag12 dual 39.45. MLP64(여러 에폭) 69.59 / 40.14까지 0.37 / 0.69%p.
  **이쪽 시스템은 데이터를 한 번씩만 봤고, MLP는 여러 에폭 + 검증 조기 종료를 썼다.**

**4. 주의**
- 격자 1회 통과는 content에서 시드 편차가 크다(±6.9). 재생을 넣으면 편차가 크게 줄어든다(±0.6).
- 재생은 격자 갱신 횟수를 늘린다 (재생 ×4 = 갱신 5배). 반복 학습 격자(grid_full, 최대 15에폭)와 비교하면 갱신 횟수는 오히려 적거나 비슷하다.
