## 해석 (2026-10-01)

1. **뉴런마다 "가장 자주 나온 클래스" 하나만 저장(top1)해도 정확도가 거의 그대로다.**
   tag12: 39.08 (full 39.22), 저장량 32,000비트 = **약 96배 압축**. wtag에서는 오히려 약간 높다 (35.96 vs 35.31).
   해마 기억의 정보는 "각 DG 뉴런이 어느 클래스를 가리키는가"에 거의 다 들어 있고, 비율값은 대부분 군더더기였다.
2. 4비트 양자화는 손실이 없고(q4 = 39.20), 2비트부터 줄어든다. 저랭크 분해는 비효율적이다(랭크 8에서 겨우 회복, 크기 0.67).
   고전 Willshaw 이진 저장(켜진 적 있으면 1)은 데이터가 많으면 거의 모든 칸이 1로 포화되어 기준선 아래로 무너진다 (14%).
3. **활성 수 k는 작을수록 좋다** (N=8000: k=10 > 20 > 40, 두 과제 모두). 희소할수록 문맥 분리가 잘 된다.
   tag12에서는 DG 뉴런의 29~43%만 쓰인다 (입력 조합이 최대 13³ = 2,197개뿐이라서) → 쓰인 뉴런만 저장하면 더 줄어든다.
4. 비교할 때 주의할 점
   - tag12에서 기억 top1(32,000비트, 39.08)은 MLP64(32비트 실수 3,340개 = 106,880비트, 40.14)보다 작지만 1%p 낮다.
     MLP도 8비트로 양자화하면 26,720비트이므로, **저장량 우위는 아직 주장할 수 없다.**
   - tag12는 입력 조합이 2,197개뿐이라 n-gram 표(2,197칸 × 4비트 ≈ 8,800비트, 39.57%)가 더 작고 더 정확하다.
     기억이 의미를 갖는 곳은 조합을 다 외울 수 없는 과제다. 그런데 그런 과제(wtag)에서는 기억 자체가 약하다 (실험 09).
   - 가지치기 점수(사전 분포와 다른 정도 × 사용 횟수)는 시드 0, n=3000의 **테스트** 데이터로 세 가지 후보를 비교해 골랐다 → 약한 선택 편향이 있다.
5. 실험 08의 공고화(기억 → 격자, 3,720개 = 119,040비트, 38.77%)보다 top1 기억(32,000비트, 39.08%)이 작고 정확하다.
   즉 **크기만 보면 수면 공고화보다 기억 자체를 압축하는 편이 낫다.** 공고화의 가치는 크기가 아니라
   "기억을 비우고 새로 받을 수 있게 한다"와 "일반화된 지식으로 바꾼다" 쪽에서 따로 확인해야 한다.
