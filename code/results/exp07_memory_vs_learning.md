## 해석

**1. 한 번만 볼 때는 기억이 압도적이다 (같은 "1회 통과" 조건 비교)**
| n=1000, 1회 통과 | content | tag12 |
|---|---|---|
| 해마형 기억 mem8k | **65.5** | **34.6** |
| MLP64 1회 | 59.3 | 25.0 |
| BioGrid C4 1회 | 56.4 | 22.5 |
- 기억은 역전파·반복 없이 한 번 본 것만으로, 같은 조건의 학습 모델보다 6~12%p 높다. n=50~300에서도 같은 경향.
- 반복 학습을 충분히 시킨 모델(검증 조기 종료까지 사용, 학습 모델에 유리한 조건)과 비교해도 소량 데이터에서 비슷한 수준:
  content n=300 기억 62.9 vs MLP64 63.7 / 격자 61.8, tag12 n=300 mem2k 31.6 vs MLP64 33.5 / 격자 29.1.

**2. 기억은 단순 암기(n-gram 표)보다 일반화한다**
- 소량 데이터에서 기억 > n-gram: content n=300 62.9 vs 58.3, tag12 n=1000 34.6 vs 31.9.
  DG 희소 부호가 비슷한 문맥을 겹치게 만들어, 처음 보는 조합에도 답을 낸다.
- 데이터가 많아지면 n-gram(외우기의 천장)에 수렴: content 69.0 vs 69.6, tag12 39.2 vs 39.6.

**3. 격자(피질)는 소량 데이터에 약하고, 많은 데이터·반복에서 따라잡는다**
- grid_full: n=300에서 61.8 / 29.1 → n=20000에서 69.5 / 39.0 (MLP64 69.6 / 40.1).
- 1회 통과로는 n=20000에서도 67.6 / 34.9.

**4. 결론: 기억과 격자는 서로의 약점을 보완한다 → 4-2(격자 + 기억 + 수면 재생)의 근거**
- 기억 = 빠른 습득, 소량 데이터 / 격자 = 느린 일반화, 대량 데이터 — 상보적 학습 시스템(CLS) 이론이 예측하는 그림 그대로.

**주의**
- 기억 모델의 저장 가중치는 16,000(content) / 96,000(tag12)개로 크다. DG 투영(8000×39)은 고정 무작위라 학습 파라미터에서 뺐지만 메모리는 차지한다.
  효율 비교는 별도 단계에서 크기를 맞춰 다시 본다.
- 셔플 대조: 기억도 기준선 이하로 떨어진다 (content 47.7~51.2, tag12 14.6~23.7) → 정답 누설 없음.
