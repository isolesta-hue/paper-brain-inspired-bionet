## 해석 (2026-10-01)

1. **격자와 함께 온라인으로 배우는 판독(R4)은 효과가 거의 없다**: content −0.48 ± 0.25, tag12 +0.12 ± 0.54, wtag +0.62 ± 0.21.
   wtag에서만 작게 오르고, 탐침 진단에서 기대한 46%에는 못 미친다.
2. 대조는 정상이다: 무작위 격자 + 판독, 셔플 + 판독 모두 정확히 찍기 기준선이다.
   → 판독만으로는 아무것도 못 배우며, 성능은 격자 내부 학습에서 나온다 (CLAUDE.md "delta rule 때문인지 분리" 항목 충족).
3. 사전 점검 (scratch, wtag 시드 0~3, 정식 결과 아님): 격자를 4에폭 학습해 **고정한 뒤** 같은 델타 규칙 판독을 20에폭 학습하면
   43.53 → 45.05 (+1.5%p, 시드별 46.16 / 45.78 / 43.86 / 44.40). 같은 시드 MLP16은 46.12.
   → 손실은 "판독이 움직이는 표현을 쫓아가지 못해서" 생긴다. 표현이 안정된 뒤 판독을 따로 정리하는 단계(수면기 판독 정리)가 후보다.
4. 시드 간 편차가 크다 (wtag 격자 42.1~45.2). 격자 학습 자체의 불안정성이 MLP와의 차이 중 큰 몫을 차지한다.
