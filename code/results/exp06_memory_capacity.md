# 실험 06: 지형을 연상 기억으로 (기억 트랙 4-1)

400뉴런 격자, 희소 패턴(40개 활성) 원샷 저장, 단서 = 활성 비트 50% + 엉뚱한 비트 4개 (단서 겹침 0.50).
값 = 회상 겹침 (원래 활성 비트를 되찾은 비율, 시드 5개 평균). **0.50보다 낮으면 기억이 단서를 망친 것.**
용량 = 겹침 ≥ 0.9를 유지한 최대 저장 개수 (시드별).

## 공간 지형 (GeoBrain F1을 기억에 사용)

패턴 길이 20 (윗줄), 활성 4개, 단서 = 활성 2개 (겹침 0.50). 아랫줄 에너지 상위 4칸을 회상으로 본다.

| 저장 개수 | 2 | 5 | 10 | 20 |
|---|---|---|---|---|
| 회상 겹침 | 0.25 | 0.16 | 0.21 | 0.21 |
## 해석

1. **"지형 = 기억"은 상태 지형으로 구현하면 성립한다.** 전체 연결 상태 지형은 절반짜리 단서로 패턴 160개(뉴런 수의 40%)까지 96% 이상 되살렸다.
   한 번 보고 저장(원샷)한 것만으로 가능하다. 희소 패턴이라 고전 홉필드의 0.14N보다 용량이 크다(희소 부호화의 알려진 이점).
2. **GeoBrain식 공간 지형은 기억으로 쓰이지 않는다.** 회상 겹침 0.16~0.25 = 무작위로 4칸을 고를 때의 기대값(4/20 = 0.20)과 같다.
   에너지가 주로 아래로만 흘러, 단서에 없는 칸으로 옮겨 가 채우는 경로가 생기지 않는다. 사용자의 직관("경험이 골짜기를 판다")은
   맞지만, 그 골짜기는 격자 공간이 아니라 "뉴런 상태들의 공간"에 파여야 한다.
3. **용량은 연결 위치가 아니라 뉴런당 연결 수가 결정한다.** 같은 연결 수에서 이웃 + 장거리(smallworld)와 완전 무작위(random)는 거의 같고,
   무작위가 약간 낫다. 이웃 8개만 연결(설계서 b-1)은 패턴 5개도 못 되살리며 오히려 단서를 망친다(0.41 < 0.50).
   - 뉴런당 약 90개 → 용량 20개, 약 180개 → 80개, 399개(전체) → 160개 이상
   - 이유: 무작위 패턴은 공간적 구조가 없어서, 빠진 비트를 채울 정보가 이웃 8칸에 거의 없다.
4. **설계에 주는 함의**: 기억 담당 영역은 국소 연결만으로는 안 되고, 해마 CA3처럼 **넓게 재귀 연결된 영역**이 필요하다.
   설계서 b-1의 "가끔 먼 연결"이나 허브(c-2)가 기억 영역에서는 핵심 역할을 해야 한다.
   단, 실제 데이터(언어)처럼 패턴에 구조가 있으면 국소 연결도 쓸모가 있을 수 있다 → 4-1b에서 확인.
