## 해석 (2026-10-01)

같은 시드끼리 짝지은 차이 (평균 ± 표준오차, 시드 5개):

| 비교 | 차이 (%p) |
|---|---|
| 격자 40 − 로지스틱 | −0.35 ± 0.26 |
| 격자 80 − 로지스틱 | +0.31 ± 0.50 |
| 격자 40 − MLP 16 | −2.02 ± 0.22 |
| 격자 80 − MLP 16 | −1.36 ± 0.42 |
| MLP 16 − 로지스틱 | +1.67 ± 0.09 |
| MLP 64 − MLP 16 | +0.50 ± 0.15 |

1. **과제가 생각만큼 어렵지 않았다.** 단어 정보로 천장은 41(품사 n-gram) → 46.7로 올랐지만,
   MLP는 은닉 16개에서 거의 포화했다 (16 → 64: +0.5, 64 → 256: 늘지 않음). "큰 모델이 필요한 과제"라는 조건을 이 과제는 충족하지 못한다.
2. **격자는 이 과제에서 로지스틱 수준이다** (40·80 모두 로지스틱과 통계적으로 구분되지 않음). MLP16보다 1.4~2.0%p 낮고,
   파라미터는 2.5~5배, 추론 연산량은 수십~수백 배 많다. tag12에서 로지스틱을 넘었던 것(38.96 vs 38.55)이 고차원 희소 입력에서는 재현되지 않는다.
3. **격자는 키워도 좋아지지 않는다**: 높이 20/40/80/160 = 43.3 / 44.2 / 44.8 / 43.6. 학습률을 크기별로 맞춰도 그렇다.
   사전 점검에서 본 "높이 80이 더 나쁨"은 학습률 때문이었지만, 맞춰도 늘어나는 폭이 없다 → **병목은 크기가 아니라 학습 규칙(신호 전달)이다.**
   시드 0에서 높이 80이 47.06%였던 것은 선택 편향이었다 (나머지 시드 42.6~45.3).
4. **해마형 기억은 고차원 단어 입력에서 실패한다**: DG 32,000(저장 384,000개)이 39.0%로, 품사 n-gram 표(41.1)에도 못 미친다.
   무작위 투영 + 상위 k 부호는 입력 39차원(tag12)에서는 문맥을 잘 분리했지만, 1,252차원 희소 입력에서는 비슷한 문맥끼리 부호가 충분히 겹치지 않아 일반화가 약하다.
5. 대조: 두 모델 모두 셔플하면 정확히 찍기 기준선(23.94)이 된다 → 학습은 진짜이고 채점 버그는 없다.

**결론**: 이 과제에서 효율 우위는 없다. 효율을 논하기 전에 고쳐야 할 것은 (a) 격자가 입력 차원이 커질 때 학습 신호를
첫 열까지 전달하지 못하는 문제, (b) 크기가 실제로 필요한 과제 설계(예: 다음 단어 자체 예측, 더 큰 어휘·데이터)다.
